# 🍫 Chocolate Sales Prediction App

👉 Live App: https://cheak-chocolat-app10.streamlit.app/

---

## 📌 About

This is a **Streamlit web application** that predicts chocolate sales amount based on user inputs like:
- Sales Person  
- Country  
- Product  
- Boxes Shipped  
- Date  

It uses a **machine learning model (RandomForestRegressor)** trained on historical data. The model is saved as **PKL** and reused to make predictions in the app.
